# Ressourcen

Alle Kurse, Bücher, Videos, Papers und Referenzen aus dem KI-Meisterlehrplan — kategorisiert und verlinkt. Jede Ressource ist kostenlos zugänglich (oder hat einen kostenlosen Audit-Modus).

!!! tip "Coursera-Audit-Modus"
    Coursera-Kurse sind im Audit-Modus kostenlos zugänglich (Materialien ja, Zertifikat nein). Beim Klick auf "Enroll" zeigt Coursera teils nur die Paid-Variante — der Audit-Link ist meistens kleiner darunter.
