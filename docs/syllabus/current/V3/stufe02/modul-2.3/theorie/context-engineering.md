# Context Engineering — neuer Begriff 2025/2026

## Kernidee

Context Engineering geht über ein einzelnes Prompt hinaus: Es fragt, wie der gesamte Kontext strukturiert ist — System-Prompt, Konversations-History, abgerufene Dokumente, Tool-Outputs. Wie ein Regisseur, der nicht nur den Dialog schreibt, sondern die gesamte Szene arrangiert: Beleuchtung, Requisiten, Hintergrund — alles beeinflusst die Performance.

## Im Detail

Die Idee, dass nicht das einzelne Prompt das Problem ist, sondern **wie der gesamte Kontext (System-Prompt + Conversation-History + Retrieval + Tool-Outputs) strukturiert ist**. Wichtig für lange Workflows und komplexe Anwendungen. Der Begriff etablierte sich 2025/2026 als die Erkenntnis wuchs, dass bei Production-Systemen das einzelne Prompt nur ein kleiner Teil des Puzzles ist. Context Engineering ist die Disziplin, den gesamten Input-Raum eines LLMs zu optimieren.
