# Few-Shot Prompting: Beispiele zeigen statt erklären

## Kernidee

Statt dem Modell lang zu erklären, was du willst, zeigst du ihm 2-5 Beispiele des gewünschten Outputs. Das ist wie "Learning by Example" — das Modell erkennt das Muster und reproduziert es. Wirksamer als Beschreibungen, besonders für spezifische Formate oder Stile.

## Im Detail

Gib dem Modell 2-5 Beispiele für die gewünschte Output-Form. Wirksamer als lange Beschreibungen, besonders wenn du ein spezifisches Format, einen bestimmten Stil oder eine konsistente Struktur brauchst. Der Name kommt aus dem Machine-Learning: "Zero-Shot" = keine Beispiele, "Few-Shot" = wenige Beispiele, "Many-Shot" = viele Beispiele. Typischer Sweet-Spot: 2-5 Beispiele. Mehr ist selten nötig und füllt das Context Window.
