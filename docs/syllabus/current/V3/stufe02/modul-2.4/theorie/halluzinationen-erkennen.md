# Halluzinationen erkennen und behandeln

## Kernidee

Halluzinationen haben typische Muster: erfundene Quellen mit plausiblen DOIs, "zu glatte" Antworten ohne Unsicherheit, Code mit nicht-existenten Funktionen. Dein Job ist nicht, Halluzinationen zu verhindern (das ist unmöglich), sondern sie zu erkennen und zu behandeln — wie ein Arzt, der Symptome kennt.

## Im Detail

Typische Muster: erfundene Quellen, falsche Zitate, plausibel klingende Statistiken ohne Beleg, Code mit nicht-existenten Funktionen, Halluzinationen bei wenig dokumentierten Themen. Standard-Gegenmittel: Quellen verlangen und verifizieren, Skepsis bei "zu glatten" Antworten, Websuche zur Gegenprüfung, bei Code die Funktionen/Libraries tatsächlich prüfen. Besonders anfällig: nischenspezifische Fachfragen, aktuelle Ereignisse, numerische Fakten, Zitate.
