# Bildgenerierung

## Kernidee

KI kann Bilder aus Text-Beschreibungen erzeugen — von fotorealistischen Porträts über Illustrationen bis zu Logos. Midjourney liefert höchste kommerzielle Qualität, DALL-E ist in ChatGPT integriert, und Stable Diffusion/Flux laufen kostenlos auf deinem eigenen Rechner. Für kommerzielle Nutzung ist Adobe Firefly rechtlich am sichersten.

## Im Detail

Midjourney (kommerziell, höchste Qualität), DALL-E 3 (in ChatGPT), Stable Diffusion (OSS, lokal lauffähig via Automatic1111 oder ComfyUI), Flux (OSS, neuere Modelle 2024-2026), Adobe Firefly (rechtssicher für kommerzielle Nutzung). Die Qualität hat 2026 ein Niveau erreicht, bei dem KI-generierte Bilder von Fotos kaum unterscheidbar sind. Für lokale Nutzung brauchst du eine GPU mit mindestens 8GB VRAM.
