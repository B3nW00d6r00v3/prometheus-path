# Spezialisierte Tools

## Kernidee

Neben den großen Chatbots gibt es hunderte spezialisierte KI-Tools, die jeweils eine Aufgabe besonders gut lösen: NotebookLM für Dokumenten-Analyse, Granola für Meeting-Notizen, Gamma für Präsentationen. Die Liste verändert sich monatlich — wichtiger als jedes einzelne Tool zu kennen ist die Fähigkeit, das richtige Tool für deinen Use-Case zu finden.

## Im Detail

NotebookLM (Google, Dokumenten-basiertes RAG mit Audio-Output), Granola (Meeting-Notizen), Cal.ai (Terminorganisation), Gamma (Präsentationen), Cursor (Coding). Die Liste verändert sich monatlich. Spezialisierte Tools sind oft besser als General-Purpose-Chatbots für ihre spezifische Aufgabe, weil sie domänenspezifische Prompts, Workflows und Daten-Integrationen mitbringen. Nachteil: Viele verschwinden wieder oder werden aufgekauft.
