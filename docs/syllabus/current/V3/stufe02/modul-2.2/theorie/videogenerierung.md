# Videogenerierung

## Kernidee

KI-Videogenerierung ist 2026 das am schnellsten sich entwickelnde Feld: Aus einer Textbeschreibung oder einem Bild entstehen kurze Videoclips. Die Qualität ist beeindruckend, aber der Bereich ist extrem volatil — monatlich erscheinen neue Tools und alte verschwinden (wie Sora 2026).

## Im Detail

Runway Gen-4.5, Kling 3.0, Veo 3.1, Luma Dream Machine, Pika. Sora wurde 2026 abgeschaltet, API läuft noch bis September 2026. Stark in Bewegung, monatlich neue Optionen. Die Technologie ist beeindruckend für kurze Clips (5-30 Sekunden), aber für längere, kohärente Videos noch nicht produktionsreif. Kosten sind typischerweise pro generierter Sekunde oder pro Auflösung.
