# Was du in 5.0 NICHT lernst

## Kernidee

Modul 5.0 gibt dir das Mindest-Fundament für Eval — bewusst schlank gehalten. Wer weiß, was hier weggelassen wird, lernt gezielter und weiß, wo er vertiefen muss.

## Im Detail

Modul 5.0 enthält absichtlich nur das Fundament. Folgendes kommt später:

| Thema | Wo es behandelt wird |
|-------|----------------------|
| **Eval-as-CI** (automatisierter Eval bei jedem Code-Change) | Modul 5.4 + Production-Querschnitt |
| **Umfassende RAG-Eval mit RAGAS** (Faithfulness, Context Precision, Answer Relevancy) | Modul 5.4 |
| **Online-Eval und Continuous Eval** (Monitoring in Production) | Production-Querschnitt |
| **Agent-Trajectory-Eval** (Evaluation von Agenten-Pfaden) | Modul 6.2 |
| **Bias-Mitigationen für LLM-as-Judge** (Position-Bias, Self-Preference) | Modul 5.4 |

**Warum diese Abgrenzung explizit machen?** Damit du nicht frustriert bist, wenn du in 5.0 kein vollständiges Eval-System aufbaust. Das Ziel hier ist Mindset — nicht Vollständigkeit.
