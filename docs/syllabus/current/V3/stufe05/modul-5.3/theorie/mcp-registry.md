# Public MCP Registry und Ecosystem 2026

## Kernidee

Über 9.400 öffentliche MCP-Server stehen in der Registry bereit — von GitHub über Postgres bis Stripe. MCP ist seit der Linux-Foundation-Donation im Dezember 2025 offiziell ein offener Standard, kein Anthropic-Proprietär-Protokoll mehr.

## Im Detail

Die MCP-Registry ist das zentrale Verzeichnis aller öffentlich verfügbaren Server. Wichtige Beispiele:

| Kategorie | Server | Typischer Use-Case |
|-----------|--------|--------------------|
| Entwicklung | GitHub, GitLab | PRs lesen, Issues erstellen |
| Datenbanken | Postgres, SQLite | DB-Queries, Schema-Inspektion |
| Dateisystem | Filesystem | Lokale Dateien lesen/schreiben |
| Kommunikation | Slack, Notion | Nachrichten senden, Pages lesen |
| Produktivität | Google Calendar, Stripe | Termine, Zahlungen |
| Search | Brave Search, Puppeteer | Web-Suche, Scraping |

**Wachstum 2026:** Monatlich +18% neue Server. Das Ecosystem hat eine kritische Masse erreicht — fast jeder SaaS-Dienst hat oder plant einen MCP-Server.

**Linux-Foundation-Donation (Dezember 2025):** MCP ist kein Anthropic-Proprietär-Standard mehr. Das bedeutet langfristige Stabilität, neutrale Governance und breitere Adoption.

**Empfehlung für Modul 5.3:** Durchsuche die Registry nach einem Server, der für deinen Alltag oder dein Capstone-Projekt relevant ist. Drei Server konsumieren ist Pflicht — die Auswahl des dritten ist frei.
