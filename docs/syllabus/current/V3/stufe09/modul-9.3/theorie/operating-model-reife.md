# Operating-Model-Reife — fünf Stufen

## Kernidee

Analog zur Datenreife (Modul 9.0) gibt es eine Operating-Model-Reife für KI — fünf Stufen von einzelnen Pilot-Experimenten bis zum strategischen KI-Differenziator. Beide Dimensionen zusammen ergeben ein vollständiges Bild der KI-Organisationsreife.

## Im Detail

| Stufe | Name | Kennzeichen |
|---|---|---|
| 1 | **Initial** | Einzelne KI-Pilots, keine Plattform, keine Governance, ad-hoc |
| 2 | **Repeatable** | Pilots erfolgreich, erste Standards (Modell-Wahl, Eval), aber keine zentrale Plattform |
| 3 | **Defined** | AI Platform existiert, Governance-Council aktiv, KPIs etabliert |
| 4 | **Managed** | NIST AI RMF / ISO 42001 umgesetzt, Continuous Improvement, mehrere Use-Cases produktiv |
| 5 | **Optimizing** | KI als strategischer Differenziator, kontinuierliche Skalierung, Cross-Org-Wissens-Transfer institutionalisiert |

**Wichtig:** Eine Organisation kann auf der Datenreife-Achse weiter sein als auf der Operating-Model-Achse — oder umgekehrt. Beide Achsen separat bewerten.

**Typischer Entwicklungspfad:**
- Stufe 1-2: Pilot-Phase, ad-hoc.
- Stufe 2-3: Plattform-Aufbau, erste Governance.
- Stufe 3-4: Governance-Reife, Skalierung.
- Stufe 4-5: strategische Integration.

**Operating Model entwickelt sich mit der Reife:** Frühe Phasen oft zentralisiert (AI Factory), reife Phasen oft federiert.
