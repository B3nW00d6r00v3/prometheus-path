# Stakeholder-Mapping vertieft

## Kernidee

Das einfache Stakeholder-Mapping aus Modul 3.3 reicht für KI-Projekte nicht aus. Fünf Dimensionen pro Stakeholder — Power, Interest, Stance, Concerns, Engagement-Strategie — geben das vollständige Bild, das für einen Change-Management-Plan nötig ist.

## Im Detail

**Fünf Dimensionen pro Stakeholder:**

1. **Power** — welchen Einfluss hat dieser Stakeholder auf die Entscheidung? (hoch / mittel / niedrig)
2. **Interest** — wie stark ist er vom Use-Case betroffen? (hoch / mittel / niedrig)
3. **Stance** — aktuelle Haltung: Champion (aktiv unterstützend), Neutral, Skeptiker (kritisch aber nicht blockierend), Blocker (aktiv gegend).
4. **Specific Concerns** — was sind die konkreten Sorgen? (Jobverlust, Datenschutz, Qualitätsbedenken, Macht-Verlust, Workload)
5. **Engagement-Strategie** — wie kommunizieren? Wie einbinden? (1:1-Gespräch, Workshop, Demo, Daten zeigen, Co-Design)

**Power-Interest-Grid + Stance (3D):**
- Hohe Power + hoher Interest + Blocker = kritischer Fall — sofortige persönliche Intervention.
- Hohe Power + niedriger Interest + Neutral = informiert halten, nicht überlasten.
- Niedrige Power + hoher Interest + Champion = aktivieren als Multiplikator.

**Für deutsche Org:** Betriebsrat hat per se hohe Power — unabhängig von Interest. Immer als Stakeholder mit Mitbestimmungsrecht einplanen.
