# Adoption-Kurve realistisch annehmen

## Kernidee

Neue KI-Tools werden nicht sofort von allen genutzt — Adoption folgt einer S-Kurve. Eine lineare Annahme von „0 auf 100% am Tag 1" ist ein klassischer ROI-Fehler, der Business Cases unglaubwürdig macht.

## Im Detail

**Realistische S-Kurve:**
- Monat 1-3: Innovators und Early Adopters (5-15% der Nutzer)
- Monat 4-8: Early Majority beginnt, wenn Pilot-Erfolge sichtbar sind (30-50%)
- Monat 9-18: Late Majority (50-80%), wenn Schulung und Champion-Netzwerk greifen
- Monat 18+: Plateau, oft unter 100% (Power User vs. Casual User)

**Eingangs-Faktoren für die Kurven-Steilheit:**
- Komplexität der Veränderung (einfaches Tool → steilere Kurve)
- Wahrgenommener Nutzen (sichtbarer Vorteil → schnellere Adoption)
- Schulungs-Verfügbarkeit (mehr Schulung → schnellere Adoption)
- Champion-Netzwerk-Stärke (starkes Netzwerk → schnellere Adoption)

**Anti-Pattern:** Lineare Kurve „wir gehen von 0 auf 100% in 6 Monaten" — das ist Wunschdenken. Auch erfolgreich eingeführte Tools erreichen selten 100% aller Mitarbeiter.
