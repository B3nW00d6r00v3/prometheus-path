# Wertschöpfungsketten-Analyse für KI-Use-Cases

## Kernidee

Jeder Schritt einer Wertschöpfungskette ist ein potenzieller KI-Use-Case-Kandidat. Wer die Wertschöpfungskette systematisch durchgeht — wo entsteht Wert, wo wird Zeit verbraucht, wo entstehen Fehler — findet Use-Cases, die operational relevant sind und nicht nur technisch interessant.

## Im Detail

**Vorgehen:**

1. **Wertschöpfungskette kartieren** — alle Schritte von Rohstoff/Input bis zum Kunden-Wert. Klassische Frameworks: Porter's Value Chain (primäre Aktivitäten: Eingangslogistik, Produktion, Marketing, Vertrieb, Service; unterstützende Aktivitäten: HR, Technologie, Beschaffung).

2. **Pro Schritt drei Fragen stellen:**
   - Wo entsteht der meiste Wert? (Priorisierung)
   - Wo wird die meiste Zeit / das meiste Geld verbraucht? (Effizienz-Potenzial)
   - Wo entstehen die häufigsten Fehler oder Eskalationen? (Qualitäts-Potenzial)

3. **Use-Case-Kandidaten je Schritt ableiten** — nicht jede Antwort ist ein KI-Use-Case, aber jede ist ein Ausgangspunkt.

4. **Business Model Canvas als Ergänzung** — für produkt- oder servicebasierte Organisationen: welche Value Propositions, Customer Segments, Key Activities hat die Organisation? Welche davon sind durch KI verbesserbar?

**Wichtig:** Wertschöpfungsketten-Analyse ohne Datenreife-Check (Modul 9.0) produziert Use-Cases, die an Daten scheitern. Immer parallel bewerten.
