# Eigene Notiz-Praxis

## Kernidee

Wer nichts notiert, vergisst alles — auch wenn es sich beim Lesen wichtig angefühlt hat. Eine minimale Notiz-Praxis (Was habe ich gelernt? Warum ist es für mich relevant? Wem würde ich das erklären?) verankert Wissen im Langzeitgedächtnis und macht es später wieder auffindbar. Das Tool ist zweitrangig — die Gewohnheit ist entscheidend.

## Im Detail

**Minimales Notiz-Schema** für jedes "Read"-Item:

- **Was**: Kernaussage in 1-3 Sätzen, in eigenen Worten
- **Warum relevant**: konkrete Verbindung zu meinen Projekten oder meinem Kontext
- **Wem erzähle ich das**: an wen denke ich sofort beim Lesen? (Feynman-Trigger: wenn du es jemandem erklären könntest, hast du es verstanden)
- **Nächste Aktion**: gibt es eine direkte Folge-Aktion (Test, Implementation, Recherche)?

**KI-Augmentation 2026:** Das Notiz-System kann mit KI erweitert werden:
- Notion AI: direkt in Notion-Notes fragen stellen
- Obsidian-Plugins (Smart Connections, Text Generator) für semantische Suche und Verknüpfungen
- Eigenes RAG-System auf Notizen (aus Modul 5.1) als fortgeschrittene Option

**Tool-Empfehlungen:**
- [Obsidian](https://obsidian.md) — lokal, kostenlos für privat, Markdown-basiert, riesiges Plugin-Ökosystem
- [Logseq](https://logseq.com) — OSS, lokal, outliner-Stil, gut für vernetzte Notizen
- [Notion](https://www.notion.so) — Cloud, kollaborativ, gute KI-Integration, aber Datenschutz beachten

**Wichtig:** Kein perfektes System aufbauen, bevor man anfängt. Ein AI-Inbox-Folder in einer Notiz-App ist besser als ein ausgefeiltes System, das nie benutzt wird.
