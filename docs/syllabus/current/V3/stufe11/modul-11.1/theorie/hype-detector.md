# Hype-Detector

## Kernidee

KI-News sind strukturell hypeanfällig: ein Demo-Video geht viral, ein Thread auf Twitter behauptet Revolution, ein Benchmark-Win wird als Durchbruch verkauft. Wer keine Skepsis-Heuristiken hat, verliert Zeit mit Phantom-Entwicklungen und schlechten Entscheidungen. Der Hype-Detector ist ein mentales Checklist-System, das in Sekunden angewendet werden kann.

## Im Detail

**Fünf Hype-Warnsignale:**

1. **"Revolution" und "wird alles verändern"** → meistens Marketing. Echte Fortschritte werden präziser beschrieben.
2. **Demo-Videos ohne Code oder Reproduzierbarkeit** → meistens Cherry-Picked. Die besten Ergebnisse wurden ausgewählt, die schlechten versteckt.
3. **Benchmark-Wins ohne Eval-Methodik** → meistens gemessen am eigenen Test-Set. "Best on benchmark XYZ" ist wertlos, wenn man das Benchmark selbst erstellt hat.
4. **"Für nur X € im Monat"** → kommerzielles Interesse. Die Person hat einen finanziellen Grund, dich zu überzeugen.
5. **Anonyme Threads mit hohen Versprechen** → meistens falsch. Jemand, der wirklich etwas Wichtiges weiß, steht mit Namen dazu.

**Goldstandard-Fragen:**
- Gibt es reproduzierbaren Code?
- Gibt es Production-Beispiele mit echten Nutzern und messbaren Ergebnissen?
- Gibt es unabhängige Replikation durch Dritte?
- Wer ist die Quelle — und welches Interesse hat sie?

**Verbindung zum Eval-Querschnitt:** Der Hype-Detector ist die Anwendung der Eval-Methodik aus `13_querschnitt_eval.md` auf den News-Konsum. Wer Evals versteht (was misst dieses Benchmark wirklich?), fällt seltener auf Demo-Hype rein.

**Gary Marcus** ist eine kontroverse, aber wichtige Stimme für KI-Skepsis — nicht weil er immer recht hat, sondern weil er systematisch die Lücken zwischen Hype und Realität benennt.
