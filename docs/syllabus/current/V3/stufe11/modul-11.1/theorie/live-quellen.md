# Live-Quellen für volatile Bereiche

## Kernidee

Bestimmte KI-Bereiche ändern sich so schnell, dass statisches Wissen innerhalb von Wochen veraltet. Modell-Rankings, Embedding-Leaderboards, Tool-Verzeichnisse — diese Inhalte muss man live abrufen, nicht einmalig lernen. Ein persönliches Lesezeichen-Set dieser Live-Quellen ist deshalb ein Pflicht-Werkzeug im KI-Profi-Repertoire.

## Im Detail

**Modell-Performance:**
- [LMSYS Chatbot Arena](https://lmarena.ai) — Community-basiertes Blind-Ranking von LLMs
- [LLM Stats Leaderboard](https://llm-stats.com) — Benchmarks und Vergleiche

**Embedding-Modelle:**
- [MTEB Leaderboard](https://huggingface.co/spaces/mteb/leaderboard) — Massiver Benchmark für Embedding-Modelle

**Open-Source-LLMs:**
- [Open LLM Leaderboard](https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard) — Benchmark für offene Modelle
- [Hugging Face Hub Trending](https://huggingface.co/models?sort=trending) — Aktuell populäre Modelle

**Tool-Landschaft:**
- [There's An AI For That](https://theresanaiforthat.com) — Verzeichnis von KI-Tools nach Use-Case
- [Future Tools](https://www.futuretools.io) — kuratiertes KI-Tool-Verzeichnis
- [Product Hunt](https://www.producthunt.com) — neue Tools täglich, sehr breites Spektrum

**MCP Servers:**
- [Public MCP Registry](https://github.com/modelcontextprotocol/servers) — verfügbare MCP-Server

**Frameworks:**
- GitHub Stars-Trending in Python/TypeScript — zeigt was die Community gerade nutzt

**Empfehlung:** Diese Lesezeichen in einem "AI Live Sources"-Browser-Ordner sammeln und quartalsweise aktualisieren (im Rahmen des 11.1-Reviews).

> *Verfallsdatum: Aug 2026 — Tool-Landschaft volatil.*
