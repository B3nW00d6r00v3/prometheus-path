# Daily Stand-up bleibt menschlich

## Kernidee

Das Daily Stand-up ist eines der wenigen agilen Rituale, bei dem KI fast keinen Mehrwert bringt. Es geht um direkte Mensch-zu-Mensch-Kommunikation: Blocker benennen, Hilfe anbieten, Kontext teilen. Wer ein KI-Tool für das Daily braucht, hat ein anderes Problem — nämlich dass das Daily nicht funktioniert.

## Im Detail

**Was das Daily ist:**

- 15 Minuten, jeden Tag, im Stehen (daher "Stand-up")
- Drei Fragen pro Person: Was habe ich gestern gemacht? Was mache ich heute? Gibt es Blocker?
- Ziel: Synchronisation im Team, nicht Status-Report an den Chef

**Warum KI hier wenig Mehrwert hat:**

- Das Daily lebt von **nonverbalen Signalen**: Tonfall, Zögern, Körpersprache. KI kann das nicht ersetzen.
- **Blocker** sind oft zwischenmenschlich oder organisatorisch — KI kennt den Kontext nicht.
- **Hilfe anbieten** erfordert Empathie und Team-Kenntnis. "Ich sehe, du steckst fest — kann ich helfen?" entsteht aus menschlicher Beobachtung.
- **Accountability** funktioniert durch soziale Dynamik, nicht durch Algorithmen.

**Einzige sinnvolle KI-Nutzung:**

- **Asynchrone Dailies:** In Remote-Teams schreiben manche das Daily als Text (Slack, Teams). KI kann über mehrere asynchrone Dailies hinweg Pattern erkennen ("Person X hat seit 3 Tagen denselben Blocker"). Aber: Das ist eher Monitoring als Daily.

**Warnsignal:** Wenn ein Team KI braucht, um das Daily "effizienter" zu machen, ist das eigentliche Problem oft: Das Daily dauert zu lang (→ zu viele Teilnehmer oder zu detaillierte Updates), das Daily ist ein Status-Report statt Synchronisation, oder das Team hat keine echte Zusammenarbeit.
