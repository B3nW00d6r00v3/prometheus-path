# IDE: Cursor oder VS Code

## Kernidee

Deine IDE ist deine Werkbank — hier schreibst, testest und debuggst du Code. Für KI-Entwicklung 2026 gibt es zwei Top-Optionen: **Cursor** (VS Code mit eingebauter KI) oder **VS Code + Continue** (Open-Source KI-Extension). Beide können dasselbe, der Unterschied ist: Cursor ist out-of-the-box fertig, Continue gibt dir mehr Kontrolle.

## Im Detail

**Cursor** — ein Fork von VS Code mit nativ eingebauten KI-Features (Autocomplete, Chat, Code-Generierung). Du öffnest es und KI funktioniert sofort. Nachteil: proprietär, kostet nach Free-Tier.

**VS Code + Continue** — die Open-Source-Variante. Continue ist eine Extension, die beliebige LLMs (auch Ollama lokal!) als KI-Backend nutzt. Vorteil: du kontrollierst, welches Modell läuft, und zahlst nichts. Nachteil: etwas mehr Setup.

**Empfehlung für dieses Curriculum:**

- Wenn du schnell starten willst → Cursor
- Wenn du OSS-First denkst oder Kosten sparen willst → VS Code + Continue
- Beide sind für alle Module geeignet, du kannst jederzeit wechseln
