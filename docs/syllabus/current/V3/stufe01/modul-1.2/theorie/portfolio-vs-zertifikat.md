# Warum Portfolio > Zertifikat

## Kernidee

Ein Zertifikat sagt: "Ich habe einen Kurs abgeschlossen." Ein Portfolio sagt: "Ich kann Problem X mit Tool Y lösen — hier ist der Beweis." In einer Welt, in der jeder KI-Kurse abschließen kann, ist das Portfolio das stärkere Signal. Recruiter öffnen dein GitHub, nicht dein LinkedIn-Zertifikate-Karussell.

## Im Detail

Zertifikate signalisieren Aufwand ("hat einen Kurs gemacht"), aber nicht Kompetenz. Ein Portfolio mit echten, dokumentierten Projekten signalisiert: "Kann Problem X mit Tools Y lösen, hat es nachweislich getan." Letzteres ist 2026 das deutlich stärkere Recruiting-Signal.

**Warum das so ist:**

- KI-Zertifikate sind inflationär — tausende Leute schließen denselben Kurs ab
- Projekte sind einzigartig — niemand hat exakt dein Problem mit deinen Daten gelöst
- Code spricht für sich — Recruiter sehen sofort Qualität, Stil, Dokumentation
- Ein Portfolio wächst mit — jedes Modul fügt ein Projekt hinzu

**Das heißt nicht:** Zertifikate sind wertlos. Sie sind ein netter Bonus, besonders für den Strategist-Track (💼). Aber sie ersetzen kein Portfolio.
