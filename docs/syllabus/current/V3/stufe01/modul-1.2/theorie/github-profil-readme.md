# GitHub-Profil-README

## Kernidee

GitHub hat ein verstecktes Feature: Wenn du ein Repo erstellst, das genauso heißt wie dein Username (z.B. `maxmustermann/maxmustermann`), wird dessen README.md direkt auf deinem Profil angezeigt. Das ist dein erster Eindruck für jeden, der dich sucht — wie eine Mini-Landingpage.

## Im Detail

**So richtest du es ein:**

1. Erstelle ein neues Repo mit deinem exakten GitHub-Usernamen als Name
2. Erstelle eine `README.md` darin
3. Der Inhalt erscheint oben auf deinem GitHub-Profil

**Was reingehört:**

- Wer du bist (1-2 Sätze)
- Was du gerade lernst (mit Link zum Portfolio-Repo)
- Welcher Track / was dein Ziel ist
- Optional: Kontakt, Social Links

**Was NICHT reingehört:**

- Überladene Badges und Widgets (weniger ist mehr)
- Veraltete Infos (lieber kurz und aktuell)
- Emojis als Ersatz für Inhalt
