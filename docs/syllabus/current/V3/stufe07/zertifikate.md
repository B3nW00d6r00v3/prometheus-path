## Hinweise zu Coursera-Audit-Modus

**DeepLearning.AI Deep Learning Specialization** (Andrew Ng) ist im **Audit-Modus** auf Coursera kostenlos zugänglich:
- Alle Video-Lectures und Readings verfügbar.
- Graded Assignments und Zertifikat: nur mit kostenpflichtigem Abo.
- Für Lernzwecke ohne Zertifikat: Audit-Modus völlig ausreichend.

So aktiviert man den Audit-Modus:
1. Coursera-Account erstellen (kostenlos).
2. Kurs öffnen, auf "Enroll for Free" klicken.
3. Im Pop-up: "Audit the course" wählen (oft klein unten).
4. Alle Video-Inhalte sind zugänglich.

Weitere Details: `99_anhang.md`.
